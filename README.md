## ⚙️ Portfolio Architecture

The portfolio itself uses a component-based Next.js architecture.
```
app/
├── page.tsx
├── About.tsx
├── Projects.tsx
└── api/
    └── quote/
        └── route.ts
```

### page.tsx

Responsible for:
- Main portfolio layout
- Hero section
- Navigation/header
- System execution monitor
- About section integration
- Project section integration
- Page-level animations

### About.tsx

Responsible for:
- Engineering narrative
- Technical focus
- Global Mindset Stream
- Quote presentation
- Architectural pillars

### Projects.tsx

Responsible for:
- Project cards
- Technology tags
- Live application links
- GitHub links
- Project descriptions
- Architecture-focused presentation
  
### /api/quote/route.ts

Provides the backend endpoint used by the portfolio's quote stream.

The endpoint is responsible for processing and filtering quote data before returning a quote to the frontend.

## 💬 Global Mindset Stream

The portfolio contains an automated quote stream designed to present ideas from thinkers and writers from different parts of the world.

The stream focuses on themes such as:

- Philosophy
- Science
- Technology
- Literature
- Personal development
- Historical thinkers
- Global perspectives

The frontend periodically requests a new quote from:
```
/api/quote
```

The returned quote is then displayed using an animated transition.

The quote stream is designed to:

- Provide perspectives from different parts of the world
- Maintain diverse global perspectives
- Reduce duplicate quotes during a browser session
- Keep the displayed quote stream varied
- Separate quote selection logic from the frontend UI

## 🛠️ Getting Started

### Prerequisites

Make sure you have installed:
- Node.js
- npm
- Git

Check your versions:
```
node --version
npm --version
git --version
```

### 📥 Installation

Clone the repository:
```
git clone https://github.com/codingbetas/himanshu-portfolio.git
```

Move into the project:
```
cd himanshu-portfolio
```

Install dependencies:
```
npm install
```

### ▶️ Development

Start the development server:
```
npm run dev
```

Open the application in your browser:
```
http://localhost:3000
```

The development server automatically reloads when source files are modified.

### 🏭 Production Build

Create a production build:
```
npm run build
```

Start the production server:
```
npm start
```

### 🔍 Code Quality & Validation

Before committing changes, I recommend running:
```
npm run build
```

This verifies that the application can successfully compile for production.

You can also inspect the Git working tree with:
```
git status
```

### 🌐 Deployment

The portfolio is designed to be deployable using modern Next.js hosting platforms.

Potential deployment platforms include:

- Vercel
- Railway
- Other Node.js-compatible hosting platforms

Once the portfolio is deployed, update the Live Portfolio link at the top of this README.

### 🔐 Environment Variables

If environment variables are introduced in the future, they should be stored locally in:
```
.env.local
```

Sensitive credentials should never be committed to GitHub.

Example:
```
API_KEY=your_api_key_here
```

For production deployments, configure secrets through the hosting provider's environment variable settings.
